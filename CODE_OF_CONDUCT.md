# Código de Conduta

O Terracota adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)
como código de conduta. Em resumo: seja gentil, acolhedor e respeitoso. Críticas vão
para o código, nunca para as pessoas. Assédio, discriminação e ataques pessoais não
são tolerados em nenhum espaço do projeto (issues, PRs, discussões).

## Como reportar

Se algo te incomodou ou você presenciou um comportamento inadequado, fale em privado
com o mantenedor pelo contato do perfil dele no GitHub. Todo relato é tratado com
sigilo, e quem reporta de boa-fé não sofre nenhuma consequência.

Os mantenedores podem remover comentários, commits, issues e outras contribuições
que desrespeitem este código, e afastar do projeto quem insistir no comportamento.
